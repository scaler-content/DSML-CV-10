    01

    The problem: verifying a signature

    You are a data scientist at a bank. A new account holder joins, and you need to set up their signature for verification. You have only one sample signature from the member. How can you use a neural network to verify signatures?

    Task: verify whether a signature is genuine or forged.

    Classification vs verification

    • Image classification identifies the class of the object in an image.
    • Image verification checks whether an image matches another image.

    Identification vs verification

    Face identification asks “who is this person?” and compares a new picture against K stored people (1-to-K). Face verification asks “is this person who they claim to be?” and compares against one stored person (1-to-1). Our signature task is a verification problem.

    Why not a traditional CNN?

    Suppose a company has 1,000 employees and wants face recognition to record attendance. A traditional classifier has two problems:

    1

    Data

    It needs many images of every employee, which is hard to collect, and a CNN trained on a handful of images per person learns weak features.

    2

    Fixed output size

    The model has 1,000 output classes, one per employee. A new employee means K+1 outputs and retraining on K+1 classes, every time. This does not scale.

    A Siamese network (a one-shot learning architecture) avoids this: it learns whether two inputs match, so a new person only needs one reference sample, with no retraining.

    02

    Siamese networks, one-shot learning and losses

    (Paper: Siamese Neural Networks for One-shot Image Recognition.)

    • A Siamese network has two or more identical subnetworks, also called twin or sister networks, with the same architecture, parameters and weights.
    • They take two different inputs, and each produces a feature vector (an embedding). The network compares the two embeddings to measure how similar the inputs are.
    • Because the weights are shared, an update to one branch is an update to the other.

    Why “one-shot”?

    A one-shot model makes correct predictions with a single training example of each new class. A Siamese network is trained with supervision to learn general features that tell whether two inputs match. Once trained, it compares a new input with a single stored example of a class it never saw in training.

    Which loss?

    The network decides “same or different” from the distance between embeddings, so it trains on pairs or triplets with losses on those distances:

    Pairs

    Contrastive loss

    Pairs from the same class end up close; pairs from different classes end up far apart.

    Triplets

    Triplet loss

    An anchor, a positive from its class and a negative from a different class.

    A binary cross-entropy loss on a pair classifier also works, and the original Siamese paper used it. Contrastive and triplet loss shape the embedding space directly, so the embeddings can be reused to compare any new pair.

  05
  
    Contrastive loss
    
  
    Contrastive loss (also called pairwise ranking loss) learns from positive pairs (same class) and negative pairs (different classes). It pulls positive embeddings together and pushes negative ones apart, up to a margin.
    
  
    
  
    L = Y · D² + (1 − Y) · max(m − D, 0)²
    Y: 1 for a similar pair, 0 for dissimilar. D: Euclidean distance between embeddings. m: margin (hyperparameter).
    
  
      
    
    • Positive pair (Y = 1): the loss is D², zero only when the embeddings coincide.
      • 
    
    • Negative pair (Y = 0): the loss is positive only while D < m. Beyond the margin it adds nothing, so easy negatives stop affecting training.
      • 
  
    
  
    
  
    
  
    Training
    
  
    Adam (learning rate 1e-4), 6 epochs, the same fit loop later reused for triplets.

  06
  
    From distance to decision
    
  
    A Siamese model outputs a distance. A signature is accepted as genuine when its distance to the reference is at most a threshold, chosen for best accuracy on the validation people and then used on the test people.
    
  
    Accuracy = (TP + TN) / (TP + TN + FP + FN)
    
  
      
    
    • TP: a genuine pair accepted as genuine. TN: a forged pair rejected as forged.
      • 
    
    • FP: a forged pair accepted as genuine (a false accept). FN: a genuine pair rejected as forged (a false reject).
      • 
    
    • TP and TN are correct predictions; FP and FN are errors.
      • 
  
    
  
    In practice, the reference signature is embedded once and each new signature is compared with it.
    
  
    
  
    Code: confusion counts, threshold search and evaluation
    
  
    Contrastive model results
    
  
    Always predicting the majority class gives 0.723 on the test pairs. The contrastive model: threshold 0.002, train accuracy 0.772, validation 0.722, test 0.724, test AUC 0.871.
    
  
    
  
    In the lecture’s example the distance was 0.078 against a threshold of 0.002, so the model said “forged signature”.
    
  
    Over the thresholds tried (0.6× to 1.4× the chosen one, 0.001 to 0.003) the lecture’s table shows a false accept rate of 0.0 and a false reject rate of 0.996 at every row: the model rejects almost every genuine pair, which is why test accuracy sits at the baseline.
    
  
    Equal error rate
    
  
    Verification systems are often summarised by the equal error rate (EER): the error at the threshold where false accept rate equals false reject rate. It does not depend on a chosen threshold, so it is a fair way to compare models (here computed at the best possible threshold on the test pairs, so it is a diagnostic, not a deployable number). Contrastive model test EER: 0.237.
    
  
    

    

    


    

    
  07
  
    Triplet loss
    
  
    Contrastive loss treats every pair on its own, asking positives to be as close as possible. Triplet loss asks for something weaker and more relative: for the same anchor, the positive must be closer than the negative by a margin. Because it does not force same-class samples to collapse to one point, the embedding can keep natural variation inside a class. (Paper: FaceNet.)
    
  
    
  
      
    
    • Anchor (A): the reference. Positive (P): same class as the anchor. Negative (N): a different class.
      • 
    
    • We want d(A,P) < d(A,N), with d the squared Euclidean distance between embeddings.
      • 
    
    • A margin α stops the network from squeezing all embeddings together: d(A,P) − d(A,N) + α < 0.
      • 
  
    
  
    L(A,P,N) = max(0, d(A,P) − d(A,N) + α)
    
  
    
  
    
    
    Easy
    d(A,N) > d(A,P) + α
    The negative is far enough. Loss is 0: nothing to learn.
    
    
    Semi-hard
    d(A,P) < d(A,N) < d(A,P) + α
    Farther than the positive but inside the margin: positive loss.
    
    
    Hard
    d(A,N) < d(A,P)
    The negative is closer than the positive: large loss.
    
  
    
  
    
  
    Which triplets are useful? Easy triplets give no gradient. Hard triplets give a strong signal, but training only on the very hardest can be unstable early on. Semi-hard triplets are often the most useful, and FaceNet selects semi-hard negatives. Triplet loss often gives good embeddings but needs careful choice of triplets.
    
  
    
  
    Code: triplet loss
    
  
    Building triplets
    
  
      
    
    • Anchor and positive are two different genuine signatures of one person: 24 × 23 / 2 = 276 combinations per person.
      • 
    
    • The negative is a forged signature of the same person, picked at random each time. This matches the real task, where the opponent is a forger imitating that person; negatives from other people would be much easier than the real test.
      • 
    
    • Triplets are built only for training people: 112 × 276 = 30,912 training triplets (10,000 sampled per epoch, the same budget as the pair model). Validation triplets use fixed negatives so the validation loss is comparable between epochs: 24 × 276 = 6,624, of which every 5th is used.
      • 
  
    
  
    
  
    Training
    
  
    The same ResNet-50 embedding network with fresh weights; only the loss and the data change. Margin 0.5, 6 epochs. After training, 96.8% of validation triplets still produced a non-zero loss.

    Data shift
    
  
    The model was trained on scanned signatures with a plain background. Phone photos have shadows and different contrast, so worse behaviour is expected. That is a useful lesson about data shift. Ideas to improve a verifier include more data, augmentation or a better loss.
    
  
    Key takeaways
    
  
      
    
    • A Siamese network has twin subnetworks with shared weights; it embeds two inputs and compares the embeddings with a distance, so new people can be verified from a single reference.
      • 
    
    • Contrastive loss learns from pairs: it pulls similar pairs together and pushes dissimilar pairs apart, up to a margin. Triplet loss makes the anchor closer to the positive than the negative by a margin; easy triplets give no signal, so triplet choice matters.
      • 
    
    • Pick a threshold on validation data and report accuracy on held-out people. Lowering the threshold trades false accepts for false rejects.
      • 
    
    • Split by person, not by pair, when the goal is to verify people the model has never seen.
      • 
    
    • In this run, triplet loss beat contrastive loss on test accuracy (0.836 vs 0.724), AUC (0.966 vs 0.871) and EER (0.095 vs 0.237).
